# TakeoffSEO — Standard Operating Procedures

How to use these: each SOP says when it applies, the steps in order, and what "done" looks like. The checklists are the same ones in the CRM (`crm/index.html`) so you tick them there, not here. Change the SOP first, then the CRM checklist, never the other way round.

Written for one person. "You" means Alexander. If someone else ever does a step, the SOP still applies to them.

Five rules that sit above every SOP:

1. Reply to every human within one business day. Even if the reply is "I'll get back to you Thursday."
2. Never promise a ranking, a position, or an AI mention. Promise the list.
3. Write the finish date down before taking money.
4. The client owns everything. Every account in their name.
5. If you wouldn't say it out loud to a plumber at a barbecue, don't write it.
